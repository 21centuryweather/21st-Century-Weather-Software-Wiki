# Global Atmospheric Modeling

**ACCESS-AM3**

ACCESS-NRI has developed a global Atmospheric (AM) suite using the Unified Model and CABLE for global simulations.

The beta release of ACCESS-AM3 is now available. You can find all relevant information at the [ACCESS-Hive Docs](https://forum.access-hive.org.au/t/access-am3-release-information/5446/5) website maintained by ACCESS-NRI.

The beta release includes 2 configurations:
* Updated n96e configuration.
* New ACCESS-AM3 n512e-aeroclim configuration from the ARC Centre of Excellence Weather of the 21st Century.

For a general overview of how to run ACCESS-AM3, check the ACCESS-NRI documentation [How to run ACCESS-AM3](https://docs.access-hive.org.au/models/run_a_model/run_access-am3/). 

> To create a new configuration and run experiments as part of 21st Century Weather, please follow the instructions in the section [How to run ACCESS-AM3 n512e](content:new-configurations) and contact the RSE team for support.
